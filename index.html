Sleep Disorder Classification using Ensemble ML

Sleep disorders are often underdiagnosed due to costly lab tests. Built an ensemble ML system using the Sleep Health & Lifestyle Dataset to automate classification — making early diagnosis faster and accessible.

Data was preprocessed using encoding and feature engineering, then trained using Stacking and Voting Classifiers. Both models achieved 92% accuracy and were validated through cross-validation.

🔍 How This Project Works

A complete explanation — from raw data to final prediction.

🎯 Goal
Predict what sleep disorder a person has — Insomnia, Sleep Apnea, or None — based on their health and lifestyle data, without needing expensive lab tests.
📦 Input Data
The model takes these real-world inputs about a person:
Age Gender Occupation Sleep Duration Sleep Quality Physical Activity Stress Level BMI Blood Pressure Heart Rate Daily Steps
1
Clean the Data
Raw data has text values like "Male" or "Engineer" — the model can't read text, so Label Encoding converts everything into numbers. Blood Pressure like "120/80" is split into two separate columns: Systolic (120) and Diastolic (80).
2
Scale the Data
Features like Age (25) and Heart Rate (75) are on different scales. Without scaling, the model thinks Heart Rate is 3x more important just because the number is bigger. StandardScaler brings all features to the same range so every feature is treated fairly.
3
Three Models Look at the Data
Random Forest — builds 100 decision trees and takes a majority vote. Like asking 100 doctors and going with the most common answer.

SVC (Support Vector Classifier) — draws the best possible boundary line that separates Insomnia, Sleep Apnea, and None from each other.

XGBoost — starts weak, then keeps learning from its own mistakes round by round until it gets strong. Like a student who reviews wrong answers and improves each time.
4
Ensemble Combines Them
Voting Classifier — all 3 models vote on the prediction. Each gives a probability score and the class with the highest combined probability wins. Think of it as 3 experts reaching a consensus.

Stacking Classifier — all 3 models make predictions, then a 4th model (meta-model) learns from those predictions and makes the final call. Like a senior doctor reviewing 3 junior doctors' reports.
5
Output — Final Prediction
The model outputs one of three labels:
✅ None 😴 Insomnia 😮‍💨 Sleep Apnea
92%
Final Accuracy
Both Voting and Stacking Classifiers achieved 92% accuracy — meaning out of 100 people, the model correctly classifies 92 of them. Validated using 5-Fold Cross Validation to ensure the result is reliable and not just luck.
