🔍 How Sleep Disorder Detection Works

A complete breakdown — from raw data to final prediction.

🎯 Problem
Sleep disorders like Insomnia and Sleep Apnea are often underdiagnosed because lab tests are costly and time-consuming. This project automates the diagnosis using machine learning — making it faster and accessible to everyone.
📦 Dataset — Sleep Health & Lifestyle
The model uses these real-world health inputs:
Age Gender Occupation Sleep Duration Sleep Quality Physical Activity Stress Level BMI Blood Pressure Heart Rate Daily Steps
1
Data Cleaning & Preprocessing
Text values like "Male" or "Engineer" are converted to numbers using Label Encoding. Blood Pressure like "120/80" is split into Systolic and Diastolic columns. Missing values are handled and data is standardized.
2
Feature Scaling
StandardScaler normalizes all features to the same range so no single feature dominates the model due to its magnitude.
3
Three ML Models
Random Forest — builds 100 decision trees and takes a majority vote.

SVC — draws the best boundary line to separate the classes.

XGBoost — learns from mistakes iteratively to get stronger each round.
4
Ensemble Methods
Voting Classifier — all 3 models vote and the class with highest combined probability wins.

Stacking Classifier — a meta-model learns from all 3 models predictions to make the final call.
5
Final Output
The model predicts one of three labels:
✅ None 😴 Insomnia 😮 Sleep Apnea
🛠️ Tools & Technologies Used
Python Pandas NumPy Scikit-learn XGBoost Random Forest SVC Stacking Classifier Voting Classifier Matplotlib Seaborn Google Colab Label Encoding StandardScaler 5-Fold Cross Validation
92%
Final Accuracy
Both Voting and Stacking Classifiers achieved 92% accuracy — validated using 5-Fold Cross Validation to ensure reliable and consistent results.

🔍 How Student Dropout Risk Predictor Works

A complete breakdown — from raw data to real-time prediction.

🎯 Problem
Educational institutions lose students to dropout every year — but they find out too late. This project predicts early which students are at risk of dropping out, so counselors can intervene before it's too late.
📦 Dataset — 4424 Students, 35 Features
Key features used for prediction:
Age at Enrollment Gender Scholarship Holder Tuition Fees Up to Date Debtor 1st Sem Subjects Approved 1st Sem Grade 2nd Sem Subjects Approved 2nd Sem Grade Unemployment Rate
1
Exploratory Data Analysis (EDA)
Analyzed patterns across 4424 students — identified that students with low 2nd semester grades, unpaid tuition fees, and fewer approved subjects are at highest dropout risk.
2
Data Preprocessing
Handled missing values, encoded categorical variables, applied StandardScaler for feature scaling, and performed train-test splitting for model readiness.
3
XGBoost Model Training
XGBoost Classifier was trained on 80% of the data (3539 students) and tested on 20% (885 students). Hyperparameter tuning was performed to optimize accuracy to 77.4%.
4
Feature Importance Analysis
Top 3 dropout predictors identified: 2nd Semester Approved Subjects, Tuition Fees Up to Date, and 1st Semester Grade.
5
Streamlit Web App
Deployed a live web application where counselors can enter student details and instantly get predictions with probability breakdown and recommended actions.
⚠️ Dropout Risk ⏳ Enrolled ✅ Graduate
